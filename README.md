# GPT01 — многоязычный перевод и Microsoft TTS

Настольное приложение для Windows на Python 3.11+ и PySide6.

## Установка

1. Распакуйте папку `gpt01` в `C:\Users\Public\Develop\gpt01\`.
2. Установите Python 3.11 или новее с python.org и включите пункт **Add Python to PATH**.
3. Запустите `setup.bat` — он создаст `.venv` и установит `requirements.txt`.
4. Запускайте приложение через `run.bat`.

## Возможности

- языковые модули English, French, Spanish, Japan и Chine;
- автоматическое переключение языка перевода и набора TTS-голосов;
- диалог `Setting` для выбора базового языка исходного текста и размера шрифта трёх окон;
- сохранение общих настроек в `settings.json`;
- три параллельных поля: оригинал, перевод и транскрипция;
- пиньинь для Chine, ромадзи для Japan и латинское написание для English/French/Spanish;
- сворачивание окна транскрипции одной кнопкой-триггером `+`/`−`;
- жёлтая подсветка строки исходника при наведении мыши;
- открытие `.txt` через кнопку или `Ctrl+O`;
- сохранение всех трёх представлений в одном файле UTF-8;
- динамический список голосов Microsoft Edge TTS для выбранного языка;
- встроенный резервный список голосов и отдельная кнопка его обновления;
- тайм-аут сетевых запросов TTS: интерфейс не остаётся в вечной загрузке;
- выбор одного голоса и проигрывание через Qt Multimedia;
- последовательное озвучивание непустых строк по кнопке «Повторить»;
- синхронная подсветка текущей строки в трёх колонках и прерывание кнопкой «Стоп»;
- перевод, загрузка голосов и синтез выполняются в фоне — окно не зависает;
- раздельные тексты, голос, компоновка, кэш голосов и MP3 в `language_data/<Language>/`;
- экспорт TXT и MP3 в папку текущего языка с суффиксами `_en`, `_fr`, `_es`, `_jp` и `_zh`;
- поддержка длинного текста через разбиение на части.
- перевод по логическим абзацам и предложениям с сохранением пустых строк и
  соответствия строк между оригиналом, переводом и транскрипцией.
- объединение соседних строк в сетевые запросы, повторные попытки при временных
  сбоях и защита от записи страниц `Error 500` в результат перевода.
- числовой индикатор обработанных частей документа во время перевода;

## Важно

Перевод выполняется через Google Translate посредством `deep-translator`, а речь — через онлайн-службу Microsoft Edge посредством `edge-tts`. Для обеих операций требуется интернет. `edge-tts` работает без Azure API-ключа, но это не официальный Azure Speech SDK. Для корпоративной эксплуатации рекомендуется заменить сервисы на официальные Microsoft Azure Translator и Azure AI Speech с ключами из переменных окружения.

Если Microsoft TTS недоступен, программа продолжит открывать, редактировать, переводить и сохранять текст. Для каждого языка доступен встроенный резервный набор голосов.

Исходные `.txt` ожидаются в UTF-8; для старых русских файлов предусмотрен запасной вариант Windows-1251.

## Архитектура

`app.py` отвечает за окно и связывает пользовательские действия с прикладными
модулями. Основная независимая логика находится в пакете `gpt01`:

- `language_controller.py` — активные языки, перевод, транскрипция и TTS-голоса;
- `session.py` — языковые каталоги, JSON-состояние, кэш и экспорт;
- `tasks.py` — фоновые операции и кооперативная отмена;
- `rows.py` — синхронизация строк трёх текстовых окон;
- `playback.py` — состояние последовательного озвучивания;
- `structured_translation.py` — сегментация предложений и структурированный перевод;
- `services.py` — внешние сервисы перевода и синтеза речи.

Проверки запускаются командами `python -m pytest -q` и
`python -m ruff check .` из активированного виртуального окружения.
