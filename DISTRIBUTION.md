# Установка VoiceGun на другом компьютере

## Системные требования

- 64-разрядная Windows 10 или Windows 11.
- Около 450 МБ свободного места для распаковки.
- Подключение к интернету для перевода через `deep-translator`, озвучивания
  через Microsoft `edge-tts` и обновления списка голосов.

Python и установка дополнительных пакетов на конечном компьютере не требуются.

## Развёртывание

1. Скопируйте архив `VoiceGun-0.4.0-windows-x64.zip` на нужный компьютер.
2. Распакуйте архив полностью в каталог, доступный пользователю для чтения и
   записи,
   например `C:\Programs\VoiceGun`.
3. Не переносите `VoiceGun.exe` отдельно от папки `_internal`: она содержит все
   необходимые библиотеки Python, Qt и языковые ресурсы.
4. Запустите `VoiceGun\VoiceGun.exe`.

Программа не требует установки и не изменяет системный реестр. Тексты, кэш
голосов, MP3 и данные языковых модулей находятся в папке `language_data` рядом с
`VoiceGun.exe`. Поэтому всю папку VoiceGun необходимо хранить в доступном для
записи месте и переносить целиком.

Общие настройки окна находятся в `settings.json`, а журнал — в `voicegun.log`
рядом с `VoiceGun.exe`. При первом запуске прежнее содержимое
`%LOCALAPPDATA%\GPT01` безопасно копируется в папку программы без удаления
оригинала и без перезаписи уже существующих файлов.

## Проверка архива

Рядом с ZIP находится файл с расширением `.sha256`. Контрольную сумму можно
проверить командой PowerShell:

```powershell
Get-FileHash .\VoiceGun-0.4.0-windows-x64.zip -Algorithm SHA256
```

Полученное значение должно совпадать со значением в файле `.sha256`.

## Возможное предупреждение Windows

Исполняемый файл пока не подписан коммерческим сертификатом. Поэтому Windows
SmartScreen может показать предупреждение для впервые загруженного архива.
Проверяйте SHA-256 и получайте архив только из доверенного репозитория проекта.
